# 项目参考图库完整恢复设计

## 目标

恢复生图页从 `projects/` 目录直接选择参考图的功能，同时保留现有本地上传和粘贴参考图能力。

## 交互设计

项目参考图库显示在生图页本地参考图上传区上方，沿用现有页面内嵌布局。

- 小灯塔：选择项目组后立即加载项目参考图。
- 画啦啦：选择项目组后显示“设计类型”下拉框，默认停留在“请选择设计类型”；选中类型后加载对应参考图。
- 图片以缩略图网格展示，点击勾选或取消，最多选择 10 张。
- 缩略图支持大图预览。
- 项目图库图片与本地上传图片可同时提交。
- 切换项目组或设计类型时清空原项目图库选择，避免跨目录误用。
- 本地上传图片仅在切换项目组时清空，选择画啦啦设计类型时不清空。

## 目录与接口

沿用现有目录解析和 HTTP 接口：

- 小灯塔优先读取 `projects/小灯塔/refs/`；不存在 `refs/` 时读取项目根目录图片。
- 画啦啦读取 `projects/画啦啦/types/<设计类型>/`。
- `GET /api/design-types?project=<项目组>` 返回设计类型及参考图数量。
- `GET /projects/<项目组>/images` 返回扁平参考图。
- `GET /projects/<项目组>/images?design_type=<类型>` 返回画啦啦类型目录参考图。

前端继续通过 `selected_project_images` 提交勾选结果，后端只注入用户明确勾选的项目图片。

## 页面状态

`shouldShowProjectRefs()` 在生图页且已选择项目组时返回真。项目参考区域恢复可见，不再使用 `feature-hidden` 隐藏。

小灯塔隐藏设计类型控件并直接加载图库。画啦啦显示设计类型控件；未选择类型时显示操作提示，不请求类型图片。切换类型后清空勾选并重新加载图库。

加载结果为空时显示对应目录说明。请求失败时显示“参考图加载失败，请刷新后重试”，并在控制台保留错误信息。

## 验证

- 静态测试确认项目参考区域不再被强制关闭。
- 静态测试确认画啦啦设计类型控件恢复显示且未选择时不加载类型图片。
- 后端测试确认小灯塔根目录图片和画啦啦类型目录图片可被列出。
- 后端测试确认所选项目图片仍能解析为安全的本地路径。
- 运行相关单元测试和页面脚本语法检查。

## 非目标

- 不新增图库弹窗、搜索、分页或收藏功能。
- 不改变本地上传参考图的数量限制。
- 不自动选择画啦啦第一个设计类型，也不在浏览器持久化上次选择。
